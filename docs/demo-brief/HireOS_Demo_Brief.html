Logisoft HireOS

AI Recruitment Platform — Demo Brief for CEO & Director
One line: HireOS reads the job, screens resumes, interviews candidates with AI, tests their skills, and gives the recruiter clear evidence — AI assists, humans decide.
Tagline: “Intelligent hiring. Human decisions.” · 100% self-hosted · Prepared 29 Sep 2026

What HireOS does

1. Manage hiringJobs, candidates, resumes, pipeline board, full activity history.
2. AI screeningMatches resume to job. Gives score, strengths, missing skills, concerns.
3. AI interviewAI asks questions by text or voice, adapts follow-ups, records answers.
4. Skill testsCoding (Python / JavaScript) and SQL tests run in a locked sandbox.
5. Integrity checksTab switch, paste, camera, optional phone as 2nd camera — flagged, not judged.
6. Evidence reportPer-answer reasoning, overall summary, skill-by-skill evidence.

Three messages to land

  1. Saves recruiter time — screening, interviewing and first-round testing run by the system.
  2. Fair and explainable — every AI score shows its reasoning; nothing is a black box.
  3. Our data stays with us — no cloud AI, no per-candidate fees, runs on our own server.
Golden rule of the product: AI never selects or rejects anyone and never moves a candidate’s stage. Only a recruiter can — and Select / Reject needs a written note.

How it is built

Frontend (what users see)

Next.js 14 + React, TypeScript, Tailwind. Recruiter dashboard, careers page, candidate portal, interview room.

Backend (logic & APIs)

Next.js API (live today). A Django + Celery backend is also built and tested, kept switched off for now.

Database

PostgreSQL with pgvector (for smart “search by meaning”). Files (resumes, recordings) on our own disk.

AI brain

Qwen 2.5 (7B) open-source model, running locally through Ollama. Nomic model for smart search.

Voice

Whisper (speech → text) and Piper (text → voice). Both run locally.

Camera & code safety

Google MediaPipe in the browser for camera checks. Docker sandbox (no internet) to run candidate code.
Everything runs on our machine / server. No OpenAI, no cloud database, no cloud storage. Candidate data never leaves the company.

Step-by-step process

#StepWhat happens
1Create jobRecruiter adds title, description, skills, experience.
2Candidates applyPublic careers page or recruiter uploads resume. Resume text read automatically.
3AI screeningOne click (or “Screen all”). Score, strengths, gaps, concerns, suggestion.
4ShortlistRecruiter moves good candidates forward on the pipeline board.
5Assessment planSystem reads the job and builds a plan: skills to test, questions, difficulty, which practical test.
6Send assessmentRecruiter clicks “Create from blueprint” / “Assign”, then shares one link with the candidate.
7Candidate takes itAI interview (about 30 min) + coding / SQL test. Integrity signals recorded if enabled.
8Auto evaluationAI scores each answer with reasoning; code/SQL checked against hidden tests.
9ReviewRecruiter sees report, transcript, skill evidence, integrity signals.
10DecisionRecruiter moves stage / selects / rejects with a note. Logged in history.

How automatic is it?

System does automatically

  • Reads resumes (PDF / Word)
  • Screening score with reasons (after one click)
  • Assessment plan from the job description
  • Interview questions (AI-worded, safety-checked)
  • Conducts the interview, asks follow-ups
  • Voice: speaks questions, transcribes answers
  • Scores each answer + overall report with reasoning
  • Runs and checks coding / SQL answers
  • Records integrity signals with timestamps
  • Keeps a full audit history of every action

Recruiter does manually

  • Create the job
  • Click “Run screening” / “Screen all”
  • Shortlist and move stages
  • Create interview / assign tests
  • Copy and send the candidate link
    (auto-email once mail server is connected)
  • Review report and evidence
  • Final Select / Reject with a note
In short: the heavy work (reading, screening, interviewing, testing, scoring) is automatic. The decisions stay human — by design.

Likely questions — short answers

Does the AI hire or reject people?
No. It only suggests. A recruiter makes every decision and must write a note.

Which AI do we use?
Qwen 2.5 — an open-source model running on our own machine via Ollama. Not ChatGPT, not cloud.

Where is candidate data stored?
On our own server — database and files. Nothing is sent outside.

What does it cost to run?
No per-candidate or per-API fees. Main cost is the server (GPU recommended).

Can candidates cheat?
We track tab switches, paste, camera and an optional phone side-camera. These are flags with time stamps for a human to review — they never change the AI score.

Is the AI fair / explainable?
Every score stores its reasoning. Recruiter sees why, not just a number.

Is it secure?
Role-based access, company data isolation, secure login, full audit trail. Candidate code runs in a locked sandbox with no internet.

How much is automatic?
Reading, screening, interviewing, testing and scoring. People create jobs, send links and decide.

Is it ready to use?
Ready for a pilot on our local server. Pending: mail server, production server setup, a few small items listed on the previous page.
